# Lab Frontend

O **lab-front** é um laboratório de estudos e experimentação em desenvolvimento frontend.

Sua proposta é isolar conceitos de programação para reforçar o aprendizado e aplicar os conhecimentos adquiridos na construção de pequenos projetos.

## Projetos

### 1. Gerenciador de Tarefas
Aplicação para adicionar, concluir e excluir tarefas.

**Tecnologias:** HTML, CSS e JavaScript.
